# EDA-Business-Intelligence
Exploratory Data Analysis &amp; Business Intelligence  This project analyzes retail sales data using Python, SQL, and visualization techniques. The objective is to uncover business insights, identify sales trends, and build a dashboard for decision-making.
Tools Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Excel

Key Insights:
- Category-wise sales analysis
- Monthly revenue trends
- Profitability by region
- Correlation analysis
- Dashboard creation
